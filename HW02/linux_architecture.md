# Архитектура ОС Linux: ядро, библиотеки, системные утилиты

Linux построена слоями: оборудование → ядро → библиотеки → системные утилиты и программы
пользователя. Каждый слой работает через нижележащий.

## a) Ядро (Kernel)

Центральная часть ОС, единственная, у которой есть прямой доступ к оборудованию. Управляет
процессами, памятью, файловыми системами, устройствами (через драйверы) и сетью. Программы
обращаются к ядру через системные вызовы (`open`, `read`, `fork` и т.д.).

**Значение:** обеспечивает стабильность и безопасность — программы не могут напрямую работать
с оборудованием или памятью друг друга.

## b) Библиотеки (Libraries)

Наборы готовых функций, которые используют программы. Главная — стандартная библиотека C
(`glibc`), которая превращает удобные функции (`printf`, `fopen`) в системные вызовы ядра.
Библиотеки бывают динамические (`.so`, общие для многих программ) и статические (`.a`).

**Значение:** программам не нужно знать детали работы ядра; общий код экономит память
и обновляется в одном месте сразу для всех программ.

## c) Системные утилиты (System utilities)

Программы для управления системой: оболочка (`bash`), работа с файлами (`ls`, `cp`, `chmod`),
процессами (`ps`, `kill`), сетью (`ip`, `ping`), службами (`systemctl`), пакетами (`apt`).

**Значение:** делают систему пригодной для работы человека — через них пользователь и
администратор управляют ОС и автоматизируют задачи скриптами.
