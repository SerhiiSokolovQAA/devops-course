# Linux: загрузка, журналы, права доступа, менеджеры пакетов

## 1. Этапы загрузки системы Linux

1. **BIOS / UEFI** — прошивка проверяет оборудование (POST) и находит загрузочный диск.
2. **Загрузчик (GRUB2)** — показывает меню выбора, загружает в память ядро и initramfs.
3. **Ядро** — инициализирует процессор, память и драйверы.
4. **initramfs** — временная файловая система в памяти, которая помогает смонтировать
   настоящий корневой раздел `/`.
5. **systemd (PID 1)** — первый процесс, запускает все службы (сеть, SSH, журналы и т.д.).
6. **Вход пользователя** — приглашение входа в консоли или графический экран входа.

## 2. Как посмотреть системные журналы

Через `journalctl` (журнал systemd):

```bash
journalctl              # весь журнал
journalctl -f           # следить в реальном времени
journalctl -b           # с текущей загрузки
journalctl -u ssh       # записи конкретной службы
journalctl -p err       # только ошибки
```

Также текстовые файлы в `/var/log` (`syslog`, `auth.log`, `kern.log`) — их просматривают
через `less`, `tail -f`, `grep`. Сообщения ядра — командой `dmesg`.

## 3. Разрешение `-rw-------`

- `-` — обычный файл;
- `rw-` — владелец может читать и изменять, но не выполнять;
- `---` — группа не имеет прав;
- `---` — остальные не имеют прав.

В числовом виде — **600**.

Добавить право на выполнение:

```bash
chmod u+x file   # только для владельца -> -rwx------ (700)
chmod +x file    # для всех
```

## 4. Разница между apt и dpkg

- **dpkg** — низкоуровневый инструмент: устанавливает локальный `.deb`-файл
  (`dpkg -i package.deb`), но не скачивает пакеты из интернета и не решает зависимости.
- **apt** — высокоуровневый менеджер поверх dpkg: сам скачивает пакеты из репозиториев,
  устанавливает зависимости и обновляет систему (`apt update`, `apt install nginx`).
